# Facebook Marketplace skill-library sharing notes

Use when preparing public posts, READMEs, demo scripts, or Sage/Hermes library descriptions for the Marketplace buyer/seller skill set.

## Pattern found from X scan

Direct `Facebook Marketplace + browser-use/agent` examples were sparse. The strongest adjacent post was artifact-first: a short X post by Tom Dörr saying “Monitors Facebook Marketplace listings with instant AI deal analysis,” linking to `BoPeng/ai-marketplace-monitor`. Its relative strength came from a concrete repo/demo/screenshot, not generic AI-agent claims.

Broad search results were dominated by low-trust auto-lister bot ads: CSV upload, image upload, form fill, automatic publish, scheduled runs, session save, and no-duplicate promises. These had weak engagement and look spammy.

## Positioning to copy

- Lead with a concrete artifact: repo, skill library, demo recording, screenshot, or reproducible workflow.
- Use a short outcome hook: deal analysis, shortlist ranking, offer ladder, listing draft, inbox triage, pickup plan.
- Make the before/after obvious: manual noisy Marketplace work -> approval-bounded agent workflow.
- Make it bookmarkable: include paths, commands, examples, or a README link.

## Positioning to avoid

- Do not market as an unattended Marketplace bot.
- Avoid “auto-publish everything,” “messages sellers automatically,” “runs forever,” or “flip items on autopilot” framing.
- Do not imply scraping, spam, ToS evasion, or payment/deposit automation.
- Do not make abstract Sage/protocol claims without a concrete Marketplace artifact attached.

## Sage/Hermes-aligned thesis

Marketplace is a good proof surface because button-clicking is not the scarce capability. The scarce capability is trusted executable judgment:

- evaluating whether a listing is real and worth pursuing
- comparing local comps and new-price anchors
- detecting flaky or suspicious counterparties
- drafting messages that stay inside approved boundaries
- knowing when to ask the operator instead of acting

Frame the library as portable operational judgment, not a one-off browser script. The buyer/seller skills show how a local workflow becomes a reusable capability asset with approval gates, provenance, and distribution.

## Good post hooks

- “Facebook Marketplace is a good test for agent skills because the hard part is not clicking buttons. The hard part is judgment.”
- “I packaged my Marketplace ops workflow as a coding-agent skill library (works in Claude Code, Codex, Hermes, etc.): scout listings, compare comps, draft offers, triage buyers, and stop before anything seller-facing without approval.”
- “A Marketplace agent that can click is a toy. A Marketplace agent that knows when not to send the message is useful.”
- “This is not an auto-lister bot. It is a set of approval-bounded skills for the messy parts of Marketplace ops.”
